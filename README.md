# Self App Builder IDE

A native Android application written in Kotlin and Jetpack Compose that allows you to write and test HTML, CSS, and JavaScript directly on your Android device.

## Features
- **Code Editor**: Write HTML, CSS, and JavaScript code.
- **Tabs**: Switch between HTML, CSS, and JS files easily.
- **Live Preview**: See the output of your code directly within the app using a WebView.
- **Persistence**: Save and load your projects locally on the device.

## Technologies Used
- Kotlin
- Jetpack Compose (Material Design 3)
- Android WebView
