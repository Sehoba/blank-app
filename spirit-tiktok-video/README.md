# Spirit – TikTok Video

Vertikales Musikvideo für **„Spirit“ von SebA_4.2.0**.

## Ausgabe

- 1080 × 1920 Pixel (9:16)
- H.264 / AAC, 30 FPS
- TikTok-, Reels- und YouTube-Shorts-kompatibel
- dezenter Zoom, unscharfer Hintergrund und Audio-Wellenform

## Neu rendern

```bash
chmod +x render.sh
./render.sh assets/erleuchtung.png assets/spirit.mp3 Spirit_TikTok_1080x1920.mp4
```

Benötigt FFmpeg mit `libx264`, `drawtext` und `showwaves`.

Quelle: [Suno – Spirit](https://suno.com/s/Or7pgED7r3c0yOcu)
